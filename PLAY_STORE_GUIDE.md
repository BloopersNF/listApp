# 🚀 MarketList - Guia de Publicação na Play Store

## 📦 Build de Produção

### Arquivos Gerados:
- **AAB (Android App Bundle)**: `android/app/build/outputs/bundle/release/app-release.aab`
- **APK de Debug**: Para testes locais

### Configurações do App:
- **Nome**: MarketList
- **Package**: com.marketlist.app
- **Versão**: 1.0.0
- **Ícone**: Com fundo azul (#4A90E2)

## 📱 Publicação na Play Store

### 1. Acesse o Google Play Console
- Vá para: https://play.google.com/console
- Faça login com sua conta Google
- Clique em "Criar app"

### 2. Informações do App
- **Nome do app**: MarketList
- **Idioma padrão**: Português (Brasil)
- **Tipo de app**: App
- **Categoria**: Produtividade
- **Gratuito/Pago**: Gratuito

### 3. Upload do AAB
1. Vá em "Versões" → "Teste interno"
2. Clique em "Criar nova versão"
3. Faça upload do arquivo `app-release.aab`
4. Adicione notas da versão:
   ```
   Primeira versão do MarketList
   - Criação e gerenciamento de listas
   - Sistema multi-idioma
   - Interface otimizada
   - Anúncios integrados
   ```

### 4. Configurar Testadores (12 pessoas mínimo)
1. Vá em "Testers" na seção de teste interno
2. Adicione emails dos testadores:
   ```
   testador1@email.com
   testador2@email.com
   ... (até 12 pessoas)
   ```
3. Ou crie uma lista de emails de teste

### 5. Informações da Loja
- **Descrição curta**: "Organize suas listas de compras de forma simples e eficiente"
- **Descrição completa**: 
  ```
  MarketList é o app perfeito para organizar suas listas de compras!
  
  🛍️ Funcionalidades:
  • Crie listas personalizadas
  • Adicione itens com preços
  • Organize por categoria
  • Interface intuitiva
  • Suporte a múltiplos idiomas
  
  📱 Simples de usar:
  • Toque para criar uma nova lista
  • Adicione itens rapidamente
  • Acompanhe o total da compra
  • Delete listas concluídas
  
  🌍 Multi-idioma:
  • Português
  • Inglês
  • Espanhol
  • Francês
  • Chinês
  ```

### 6. Screenshots Necessários (4-8 imagens):
- Tela principal com listas
- Tela de criação de lista
- Tela de itens da lista
- Tela de configurações

### 7. Ícone da Loja
- Usar o mesmo ícone com fundo azul
- Formato: 512x512px PNG

### 8. Banner de Destaque (Opcional)
- Tamanho: 1024x500px
- Pode usar o logo + texto "MarketList"
